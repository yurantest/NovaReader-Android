# NovaReader Android

Android-версия NovaReader — современной читалки на базе собственного движка **Immortal Book Core**, используемого также в версии NovaReader для ПК.

Большинство ключевых возможностей настольной версии перенесено на Android: чтение EPUB/FB2 и других форматов, закладки, подсветки и выделения текста, цитаты, прогресс чтения, резервное копирование, поиск, настройка оформления и другие функции.

**Immortal Book Core** обеспечивает единую логику работы с книгами и чтением на разных платформах, а Android-версия использует нативный интерфейс и системные возможности устройства.

Проект продолжает развиваться вместе с основной версией NovaReader.
